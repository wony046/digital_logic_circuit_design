# 디지털 논리 회로 설계 VHDL 과제

## 파일 구성

| 문제 | VHDL 소스 | Logisim 프로젝트 |
|---|---|---|
| 1. 4입력 AND 및 OR | logic4.vhd | homework_01.circ |
| 2. 8:1 MUX | mux8.vhd | homework_02.circ |
| 3. 문자 표시 | letters7seg.vhd | homework_03.circ |
| 4. 25인 투표 회로 | vote25.vhd | homework_04.circ |
| 5. 15비트 개수 세기 및 표시 | popcount15.vhd | homework_05.circ |

`homework_all.circ`에는 위 다섯 회로가 함께 들어 있습니다. [편집용 Word 보고서](report/report.docx)는 기존 NOT 게이트 보고서의 구성과 문체를 바탕으로 작성한 편집용 Word 보고서이며, [제출용 PDF 보고서](report/report.pdf)는 같은 문서의 제출용 PDF입니다. 그림과 코드 전문은 모두 표 안에 배치했고, 코드는 Word에서 직접 편집할 수 있는 텍스트로 넣었습니다. `verification` 폴더에는 실제 컴파일과 자동 검증 결과가 있습니다. 모든 VHDL 소스와 회로 파일에 포함된 VHDL 코드는 주석을 제거했습니다.

## 실행 방법

사용 환경은 Windows의 Logisim-evolution 5.0.0과 Questa Altera Starter FPGA Edition 2025.2입니다.

1. Logisim의 File 메뉴에서 Open을 선택하여 `homework_all.circ`를 엽니다.
2. 왼쪽 목록의 `task1_logic4`부터 `task5_popcount15`까지 원하는 회로를 더블클릭합니다.
3. 다른 프로젝트에서 실행 중인 VHDL 시뮬레이션과 Questa 창을 종료한 뒤, 현재 프로젝트에서만 Simulate 메뉴의 VHDL Simulation Enabled를 켭니다.
4. 손가락 도구로 입력핀의 비트를 눌러 값을 바꾸고 출력을 확인합니다.

Windows 탐색기에서는 `.vhd`가 하드디스크 이미지로 표시될 수 있습니다. `.vhd`를 직접 불러올 때는 Logisim의 Project 메뉴에서 Import VHDL Entity를 사용합니다. 이 제출물의 `.circ`에는 소스가 이미 포함되어 있어 별도 불러오기가 필요하지 않습니다.

## 입력과 예상 동작

- 1번: 네 입력이 모두 1이면 out1이 1이고, 하나라도 1이면 out2가 1입니다.
- 2번: sel의 000부터111까지 각각 a부터h까지의 입력을 y로 전달합니다.
- 3번: sel의 000,001,010,011,100,101에 각각 a,b,c,d,f,g를 표시합니다. 110과111에서는 표시를 끕니다.
- 4번: vt는25비트입니다. 1의 개수가12개이면 result=0,13개이면 result=1입니다.
- 5번: vt는15비트입니다. en=0이면 표시가 꺼지고,en=1이면 1의 개수를 표시합니다. 10, 11, 12, 13, 14, 15는 각각 A, b, C, d, E, F로 표시합니다.

7세그먼트에서는 입력1에 해당하는 막대가 켜집니다. 같은 이름의 `seg_a`부터 `seg_dp`까지 터널은 전기적으로 연결되어 있습니다. 소수점 dp는 항상 꺼져 있습니다.

## 5번의 입력 범위

표시할 개수 0~15가 모두 발생하도록 입력 vt를15비트 벡터로 구성했습니다. 입력 범위는 vt(14 downto 0)이며,1의 개수0~9는 숫자,10~15는 A,b,C,d,E,F로 표시합니다. B와D는7세그먼트에서 구분하기 쉬운 소문자 b와d 형태로 표시했습니다.

## 실제 자동 검증 결과

Questa의 VHDL-93 모드에서 컴파일 오류0개 및 경고0개를 확인했습니다. 테스트벤치로 총67,684개 조건을 검사했고 모두 통과했습니다.

| 모듈 | 검증한 조건 수 |
|---|---:|
| logic4 | 16 |
| mux8 | 2,048 |
| letters7seg | 8 |
| vote25 | 76 |
| popcount15 | 65,536 |

5번은 가능한32,768개 입력 각각에 대해 en=0과en=1을 검사했습니다. 4번은0부터25까지의 찬성 수와12명/13명 경계에서 비트 위치를 바꾼 조건을 검사했습니다. 이 결과는 소스 동작의 자동 검증 결과이며,보고서의 Logisim 그림은 회로 배치 및 배선을 보여줍니다.
